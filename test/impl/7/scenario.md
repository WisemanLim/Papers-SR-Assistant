# 기능 구현 7차(impl/7) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 7차 구현분의 정상 작동 여부를 검증한다.
7차 구현 범위:
- **[NFR §5-2] 반응형 웹 (태블릿 지원)**:
  - ≤1180px (태블릿 가로): 열 비율 27/46/27 조정, 헤더 슬림화 (프리셋 라벨·버전 태그 숨김).
  - ≤920px (태블릿 세로): 중앙 그래프 전폭, 좌(큐시트)·우(상세) 패널을 슬라이드 오버레이로 전환 —
    헤더 토글 버튼 2개 + 백드롭 클릭 닫기. 검색 드롭다운 폭 vw 제한.
  - 데스크톱(>1180px) 기존 3열 레이아웃 불변.

## 2. 사전 조건
- `pnpm build` / `pnpm lint` 통과 (회귀 없음).
- `pnpm dev` 로 `http://localhost:5173/` 기동. 시작 시 localStorage `psra:*` 초기화.
- Playwright(Chromium) 뷰포트 전환(1600 → 1024 → 800 → 1600)으로 검증.
- 원본 로그는 `logs/` 저장.

## 3. 케이스 표

| id | 목적 purpose | 입력 input | 기대결과 expected | 우선순위 |
|---|---|---|---|---|
| TC-01 | 빌드/린트 회귀 | `pnpm build`, `pnpm lint` | 빌드 성공, 신규 린트 오류 0건 | P0 |
| TC-02 | 데스크톱 회귀 | 뷰포트 1600×1000 | 3열 표시, 토글 버튼 숨김, 가로 오버플로 없음 | P0 |
| TC-03 | 태블릿 가로 | 뷰포트 1024×768 | 3열 유지(조정 비율), 가로 오버플로 없음 | P0 |
| TC-04 | 태블릿 세로 전환 | 뷰포트 800×1100 | 좌·우 패널 화면 밖(오버레이 대기), 중앙 전폭, 토글 버튼 2개 표시 | P0 |
| TC-05 | 좌측 오버레이 | 큐시트 토글 클릭 → 백드롭 클릭 | 패널 슬라이드 인(백드롭 표시) → 백드롭 클릭 시 닫힘 | P0 |
| TC-06 | 우측 오버레이 + 상호작용 | 상세 토글 클릭 → 패널 내 버튼 확인 | 상세 패널 열림, "큐시트에 담김/추가" 버튼 접근 가능 | P0 |
| TC-07 | 그래프 동작 (800px) | 캔버스·recenter 버튼·검색 드롭다운 | 캔버스 렌더, recenter 클릭 정상, 드롭다운 폭 ≤ 뷰포트 | P0 |
| TC-08 | 데스크톱 복귀 | 뷰포트 1600×1000 재설정 | 3열 복원, 백드롭 비표시, 오버레이 잔존 없음 | P1 |
| TC-09 | 콘솔 무결성 | 전체 흐름 | 콘솔/페이지 에러 0건 | P0 |

## 4. 판정 기준
- P0 전건 PASS 필수. P1 실패 시 원인 분석 후 수정·재시험.
