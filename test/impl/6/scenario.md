# 기능 구현 6차(impl/6) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 6차 구현분의 정상 작동 여부를 검증한다.
6차 구현 범위:
- **[FR-1.3] 추천 엔진 랭킹**: 시드 논문 기준 연관 논문 점수화 (`src/lib/recommend.js`) —
  직접 인용(0.4) + Bibliographic Coupling(0.2) + Co-citation(0.15) + 제목/요약 토큰 Jaccard 유사도(0.25) 조합.
  큐시트 좌측 하단 "추천 논문" 섹션: 관련도 % 내림차순, 원클릭 추가. (임베딩 유사도는 Phase 2 LLM 연동 시 고도화)
- **[FR-2.1 잔여] 연도 기반 노드 색상**: 일반 노드 색상을 발행 연도 → 색상(hue 200~280) 매핑,
  범례 "일반 논문 (색=연도)" + 그라데이션 스와치. 선택(보라)·시드(파랑) 오버라이드 유지.

## 2. 사전 조건
- `pnpm build` / `pnpm lint` 통과 (회귀 없음).
- `pnpm dev` 로 `http://localhost:5173/` 기동. 시작 시 localStorage `psra:*` 초기화 (이전 세션 영속 데이터 배제).
- Playwright(Chromium) 자동화, 외부 논문 케이스는 S2 응답 `page.route` 목킹.
- 원본 로그는 `logs/` 저장.

## 3. 케이스 표

| id | 목적 purpose | 입력 input | 기대결과 expected | 우선순위 |
|---|---|---|---|---|
| TC-01 | 빌드/린트 회귀 | `pnpm build`, `pnpm lint` | 빌드 성공, 신규 린트 오류 0건 | P0 |
| TC-02 | 추천 기본 렌더 | 기본 상태 (시드 Transformer, 큐시트 4편) | 추천 2건 (RoBERTa·DeiT, 직접 인용 시드) + 관련도 % 표시 | P0 |
| TC-03 | 랭킹 내림차순 | 추천 목록의 % 값 | 내림차순 정렬, 전건 40% 이상 (직접 인용 가중치 반영) | P0 |
| TC-04 | 원클릭 추가 | 추천 1건 "＋" 클릭 | 큐시트 5항목, 추천 목록 1건으로 감소 | P0 |
| TC-05 | 후보 소진 처리 | "전체 계보" 프리셋 (6편 전부 큐시트) | 추천 0건 + "추천할 논문이 없습니다" 안내 | P1 |
| TC-06 | 시드/큐시트 변경 반영 | "NLP 계보" 프리셋 (시드 BERT, 큐시트 3편) | 추천 3건 (ViT·DeiT·Swin — 서지 결합/유사도 기반) | P0 |
| TC-07 | 외부 논문 추천 편입 | 검색으로 Transformer 직접 인용 논문 추가 (목킹, 큐시트 미편입) | 추천 목록 최상단 진입 (직접 인용 최고 가중치) | P0 |
| TC-08 | 연도 색상 범례 | 초기 화면 | 범례 "일반 논문 (색=연도)" + 스크린샷 증적 (canvas 내부 색상은 시각 확인) | P1 |
| TC-09 | 회귀: MD 내보내기 | "MD" 클릭 | STEP 수 = 큐시트 수, 읽기 근거 라인 포함 | P1 |
| TC-10 | 영속성 회귀 | 새로고침 | 큐시트·외부 논문 유지, 추천 섹션 일관 재계산 | P0 |

## 4. 판정 기준
- P0 전건 PASS 필수. P1 실패 시 원인 분석 후 수정·재시험.
