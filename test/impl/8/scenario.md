# 기능 구현 8차(impl/8) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 8차 구현분의 정상 작동 여부를 검증한다.
8차 구현 범위:
- **[PRD Phase 3] 큐시트 공유 링크 생성 (서버리스)**: 워크스페이스(큐시트·시드·정렬·메모·외부 논문·
  인용 엣지 패치)를 URL 해시(`#share=`)에 유니코드 안전 base64 로 인코딩 (`src/lib/share.js`).
  - 큐시트 헤더 "공유" 버튼 → 링크 생성 + 클립보드 복사 + "복사됨" 피드백.
  - 공유 URL 접속 시 confirm 후 워크스페이스 대체 복원 (거부 시 유지), 처리 후 해시 제거.
  - 손상 해시는 무시하고 정상 로드. 백엔드 불필요.

## 2. 사전 조건
- `pnpm build` / `pnpm lint` 통과 (회귀 없음).
- `pnpm dev` 로 `http://localhost:5173/` 기동. 각 단계 시작 시 localStorage `psra:*` 초기화.
- Playwright(Chromium) 자동화 + clipboard 권한 부여, 외부 논문은 S2 응답 목킹.
- 원본 로그는 `logs/` 저장.

## 3. 케이스 표

| id | 목적 purpose | 입력 input | 기대결과 expected | 우선순위 |
|---|---|---|---|---|
| TC-01 | 빌드/린트 회귀 | `pnpm build`, `pnpm lint` | 빌드 성공, 신규 린트 오류 0건 | P0 |
| TC-02 | 공유 링크 생성 | 메모·수동 정렬·외부 논문 구성 후 "공유" 클릭 | 클립보드에 `#share=` URL, 버튼 "복사됨" 피드백 | P0 |
| TC-03 | 공유 가져오기 | 초기화된 브라우저에서 공유 URL 접속 + confirm 수락 | 큐시트·메모·정렬 모드·시드 복원, 해시 제거 | P0 |
| TC-04 | 외부 논문 라운드트립 | TC-03 상태 검증 확장 | 외부 논문 포함 노드 7, 인용 엣지(선행 필터) 유지 | P0 |
| TC-05 | 가져오기 거부 | 공유 URL 접속 + confirm 취소 | 기본 상태(6노드) 유지, 해시 제거 | P0 |
| TC-06 | 손상 해시 방어 | `#share=broken!!` 접속 | confirm 미발생, 정상 로드, 페이지 에러 0건 | P0 |
| TC-07 | 재공유 결정성 | 가져온 워크스페이스에서 재공유 | 디코딩 payload 필드 원본과 동일 (라운드트립 무손실) | P1 |
| TC-08 | 회귀 | 가져오기 후 추천 섹션·MD 내보내기 | 정상 동작 (읽기 근거 포함) | P1 |

## 4. 판정 기준
- P0 전건 PASS 필수. P1 실패 시 원인 분석 후 수정·재시험.
