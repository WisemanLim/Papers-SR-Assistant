# 기능 구현 2차(impl/2) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 2차 구현분의 정상 작동 여부를 검증한다.
2차 구현 범위 (PRD Phase 1 잔여 항목):
- **[FR-3.3] 큐시트 드래그 앤 드롭 정렬 + 항목별 메모**: 수동 편집 모드에서 카드를 드래그하여 순서 변경, 논문별 메모 추가/수정/삭제.
- **[FR-2.2] 관계 필터링**: 선택 논문 기준 선행 연구(Prior)/후속 연구(Derivative)/유사 연구(Similar) 그래프 필터.
- **[FR-5.1] 내보내기 확장**: 기존 Markdown 에 더해 CSV(.csv), BibTeX(.bib) 내보내기.

## 2. 사전 조건
- `pnpm build` / `pnpm lint` 통과 (회귀 없음).
- `pnpm dev` 로 `http://localhost:5173/` 기동.
- Playwright(Chromium) 자동화로 검증, 원본 로그는 `logs/` 저장.

## 3. 케이스 표

| id | 목적 purpose | 입력 input | 기대결과 expected | 우선순위 |
|---|---|---|---|---|
| TC-01 | 빌드/린트 회귀 | `pnpm build`, `pnpm lint` | 빌드 성공, 신규 린트 오류 0건 | P0 |
| TC-02 | 초기 로드 회귀 | `/` 접속 | 3열 레이아웃 + 그래프 + 관계 필터 탭 4개 렌더 | P0 |
| TC-03 | 후속 연구 필터 | BERT 선택 → "후속 연구" 클릭 | 그래프에 BERT + RoBERTa 만 표시 (노드 2개) | P0 |
| TC-04 | 선행 연구 필터 | BERT 선택 → "선행 연구" 클릭 | BERT + Transformer 만 표시 (노드 2개, 이행적 참조 포함) | P0 |
| TC-05 | 유사 연구 필터 | ViT 선택 → "유사 연구" 클릭 | 동일 분야(Vision) 또는 참조 공유 논문 5개 표시, Transformer 제외 | P1 |
| TC-06 | 관계 필터 해제 | "관계: 전체" 클릭 | 전체 6개 노드 복원 | P1 |
| TC-07 | 수동 모드 전환 | 정렬 모드 → "사용자 수동 편집" | 현재 표시 순서 유지 채택, 드래그 힌트 배너 + 그립 핸들 표시 | P0 |
| TC-08 | 드래그 앤 드롭 정렬 | 1번 카드를 3번 위치로 드래그 | STEP 배지 순서 재배열, 순서 영속 | P0 |
| TC-09 | 메모 추가/수정 | 메모 버튼 → 텍스트 입력 → Enter | 메모 칩 표시, 재클릭 시 수정 가능 | P0 |
| TC-10 | CSV 내보내기 | "CSV" 버튼 클릭 | `Papers-CueSheet-*.csv` 다운로드, BOM + 헤더 13열 + 큐시트 행 수 일치, 따옴표 이스케이프 | P0 |
| TC-11 | BibTeX 내보내기 | 전체 계보 프리셋 → "BibTeX" 클릭 | `Papers-CueSheet-*.bib` 다운로드, 6개 엔트리, arXiv(RoBERTa)=@article, 그 외=@inproceedings | P0 |
| TC-12 | MD 내보내기 + 메모 반영 | 메모 입력 후 "MD" 클릭 | `.md` 다운로드, 해당 STEP 에 `📝 내 메모` 라인 포함 | P1 |

## 4. 판정 기준
- P0 전건 PASS 필수. P1 실패 시 원인 분석 후 수정·재시험.
