# 기능 구현 5차(impl/5) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 5차 구현분의 정상 작동 여부를 검증한다.
5차 구현 범위:
- **[PRD Phase 1 "저장"] 워크스페이스 영속성**: 외부 추가 논문·인용 엣지 패치·큐시트·시드·메모·정렬 모드를
  localStorage 에 저장/복원 (`src/lib/storage.js`). 헤더에 워크스페이스 **초기화 버튼** (confirm 후 영속 데이터·캐시 삭제).
- **[FR-2.1 양방향] 피인용 방향 엣지 연결**: 논문 추가 시 참조(선행)에 더해 피인용(citations/cites) 조회로
  컬렉션 내 후속 논문 → 새 논문 방향 엣지 자동 생성 (S2 `/citations` · OpenAlex `filter=cites:`).
- **[NFR §5-1] API 응답 캐싱**: 검색·참조·피인용 응답을 localStorage 캐시 (TTL 24h, `src/lib/cache.js`) —
  동일 요청 재발생 시 네트워크 호출 생략, 오류는 캐시하지 않음.

## 2. 사전 조건
- `pnpm build` / `pnpm lint` 통과 (회귀 없음).
- `pnpm dev` 로 `http://localhost:5173/` 기동.
- Playwright(Chromium) 자동화, API 응답 `page.route` 목킹 (전 케이스 — 영속성·캐시는 로컬 기능이라 실 API 불필요).
- 원본 로그는 `logs/` 저장.
