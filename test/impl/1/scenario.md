# 기능 구현 1차(impl/1) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant MVP 웹 애플리케이션의 핵심 비즈니스 요구사항(인용 관계 네트워크, 큐시트, 상세 요약 카드, AI 질의응답 및 마크다운 내보내기)의 정상 작동 여부를 검증하기 위한 것입니다.

## 2. 테스트 대상 기능
- **시간축 인용 네트워크 시각화**: 연도별 정렬, 노드 크기(피인용수 비례), 색상(선택/시드/일반), 클릭 및 확대/축소/recenter.
- **큐시트 로드맵**: 위상 정렬(Topological Sort) 및 연도별 정렬, 수동 정렬 버튼, 큐시트 내보내기.
- **상세정보 카드**: 논문 메타데이터, 국문 TL;DR, 기여도 및 한계점 표, 수식 설명 카드 및 LaTeX 렌더링.
- **AI 질의응답**: 문맥 기반 답변 시뮬레이터.
- **마크다운 내보내기**: 정리된 큐시트를 파일(`.md`)로 로컬 PC 다운로드.

## 3. 테스트 시나리오 및 수행 절차
### 시나리오 1: 초기 페이지 로드 및 네트워크 시각화 검증
1. `http://localhost:5173/` 접속.
2. 3열 레이아웃(좌: 큐시트, 중: 네트워크, 우: 상세카드)이 올바르게 렌더링되는지 확인.
3. 중앙 패키지 영역에 2017년부터 2021년까지의 시간축 정렬 세로선이 보이고, 논문 노드들이 좌표에 맞게 정상적으로 드로잉되는지 검증.

### 시나리오 2: 노드 선택 및 상세 카드 연동 검증
1. 중앙 네트워크 그래프에서 "BERT: Pre-training of Deep..." 노드를 마우스 클릭.
2. 우측 상세 요약 카드가 BERT의 정보로 갱신되는지 확인 (저자: Jacob Devlin, 학회: NAACL 2018 등).
3. "AI 1줄 요약(국문)", "핵심 요약 테이블" 및 수식 설명 카드의 LaTeX($\text{Masked LM Loss}$, $\text{Next Sentence Prediction}$)가 수식 폰트로 정상 렌더링되는지 검증.

### 시나리오 3: 계보 프리셋 필터링 검증
1. 상단 헤더의 "NLP 계보" 버튼 클릭.
2. 중앙 그래프에 NLP 계보 논문(Transformer, BERT, RoBERTa)만 필터링되어 나타나는지 확인.
3. 좌측 큐시트 로드맵에 해당 논문들만 목록화되는지 검증.
4. "비전 계보" 버튼 및 "전체 계보" 버튼을 차례로 눌러 필터링이 즉각 반응하는지 확인.

### 시나리오 4: AI 대화형 질의응답 검증
1. 우측 상세 패널의 "AI 질의응답" 탭을 클릭.
2. 입력란에 "핵심 기여점" 등을 작성 후 전송(Send) 버튼 클릭.
3. 2초 대기 후, AI 챗봇이 해당 논문의 문맥을 정확히 반영한 친절한 대화형 마크다운 응답을 반환하는지 확인.

### 시나리오 5: 마크다운 큐시트 내보내기 검증
1. 좌측 큐시트 헤더의 "내보내기" 버튼 클릭.
2. 브라우저에서 `Papers-CueSheet-YYYY-MM-DD.md` 이름의 다운로드 팝업이 활성화되거나 파일이 다운로드 폴더에 안전하게 생성되는지 검증.
