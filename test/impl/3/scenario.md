# 기능 구현 3차(impl/3) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 3차 구현분의 정상 작동 여부를 검증한다.
3차 구현 범위 (PRD Phase 1 잔여 항목):
- **[FR-1.1] 학술 검색**: 검색 바에서 Enter 입력 시 Semantic Scholar Graph API 실검색 (키워드·제목·DOI·arXiv ID).
- **[FR-1.2] 컬렉션 확장**: 검색 결과를 컬렉션에 추가, 참조 목록을 조회해 기존 컬렉션 논문과 인용 엣지 자동 연결 (S2 paperId → 정규화 제목 순 매칭).
- **타임라인 동적화**: 추가 논문의 연도에 맞춰 그래프 X축·연도 가이드라인 범위 자동 확장 (라벨 최대 ~8개 스텝 조정).

## 2. 사전 조건
- `pnpm build` / `pnpm lint` 통과 (회귀 없음).
- `pnpm dev` 로 `http://localhost:5173/` 기동.
- Playwright(Chromium) 자동화. **결정적 검증을 위해 API 응답은 `page.route` 목킹** (TC-02~09, TC-11),
  실제 API 스모크는 별도 케이스 (TC-10, 공용 rate-limit 으로 실패 시 SKIP 허용).
- 원본 로그는 `logs/` 저장.

## 3. 케이스 표

| id | 목적 purpose | 입력 input | 기대결과 expected | 우선순위 |
|---|---|---|---|---|
| TC-01 | 빌드/린트 회귀 | `pnpm build`, `pnpm lint` | 빌드 성공, 신규 린트 오류 0건 | P0 |
| TC-02 | 원격 검색 트리거 | 검색어 입력 + Enter (목킹) | 드롭다운에 결과 목록 + 제목·연도·피인용 표시 | P0 |
| TC-03 | 논문 추가 | 결과의 "추가" 클릭 | 그래프 노드 6→7, 추가 논문 자동 선택, 상세 패널에 대체 필드("—") 표시 | P0 |
| TC-04 | 참조 자동 연결 | 추가 논문 선택 → "선행 연구" 필터 | 참조 title 매칭으로 Transformer 와 연결 → 노드 2개 표시 | P0 |
| TC-05 | 타임라인 동적 확장 | 2022년 논문 추가 후 | 연도 가이드라인에 "2022" 라벨 생성 | P0 |
| TC-06 | 중복 추가 방지 | 동일 논문 재검색 | 버튼이 "추가" → "보기" 로 표시, 노드 수 불변 | P1 |
| TC-07 | API 오류 처리 | 검색 API 500 응답 (목킹) | 드롭다운에 오류 메시지 표시, 앱 크래시 없음 | P0 |
| TC-08 | 결과 없음 처리 | 빈 결과 응답 (목킹) | "검색 결과가 없습니다." 표시 | P1 |
| TC-09 | 드롭다운 닫기 | Escape 키 / 닫기 버튼 | 드롭다운 소멸 | P1 |
| TC-10 | 실 API 스모크 | 목킹 해제 후 "attention is all you need" 검색 | 결과 ≥ 1건 (rate-limit 시 SKIP 기록) | P2 |
| TC-11 | 큐시트 회귀 + 통합 | 추가 논문을 큐시트에 담고 MD 내보내기 | 큐시트 카드 생성(대체 근거 문구), MD 에 해당 STEP 포함 | P0 |

## 4. 판정 기준
- P0 전건 PASS 필수. P1 실패 시 수정·재시험. P2(TC-10)는 외부 서비스 가용성 의존 — 실패 시 사유 기록 후 SKIP 가능.
