# 개발 환경(dev-env) 테스트 시나리오

## 1. 개요
본 시나리오는 Papers-SR-Assistant 프로젝트의 로컬 개발 및 빌드 환경이 비즈니스 요구사항을 충족하고 오작동 없이 빌드/기동될 수 있는지 검증하기 위한 것입니다.

## 2. 테스트 환경 정보
- **운영체제(OS)**: macOS (M-series / Intel)
- **Node.js 버전**: v22.23.1 이상
- **패키지 매니저**: pnpm v11.10.0 이상
- **프레임워크**: Vite 8.1.4 / React 19.2.7

## 3. 검증 항목 및 절차
### 항목 1: 의존성 설치 및 무결성 검증
- **설명**: `pnpm install`을 수행하여 오류 없이 의존성이 정상적으로 해결 및 설치되는지 확인합니다.
- **예상 결과**: 취약점이 발견되지 않고, 모든 패키지가 무결성 검증을 통과하여 설치가 완료됩니다.

### 항목 2: 프로덕션 빌드 (Production Build)
- **설명**: `npm run build`를 실행하여 Vite 환경에서 오류 없이 정적 애셋 빌드가 완성되는지 확인합니다.
- **예상 결과**: 번들링 및 미니피케이션이 통과되어 `dist/` 디렉터리가 에러 없이 생성되어야 합니다.

### 항목 3: 개발 서버 구동 (Development Server)
- **설명**: `npm run dev` 또는 `vite` 명령어를 실행하여 로컬 포트 `5173`에서 개발 서버가 에러 없이 기동되는지 확인합니다.
- **예상 결과**: 개발 서버가 정상 시작되고, `localhost:5173`으로 접속이 가능한 상태가 됩니다.
